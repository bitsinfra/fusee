# Get started with Fusee

Fusee is a library for workflows that need to survive a restart. Write a function in your language, wrap work in named steps, and let Fusee record their results. When the process restarts, the workflow can reuse a recorded result and continue from there.

## Your first workflow

[Install the SDK and CLI](installation.md), then follow the quickstart for your language. You'll build a workflow that greets someone, waits for approval, and resumes after you kill the process.

<Tabs groupId="sdk" persist items={["TypeScript", "Python", "Rust"]}>

<Tab value="TypeScript">

```ts
import { workflow } from "fusee";

export const greet = workflow("greet", async (ctx, name: string) => {
  return await ctx.step("compose", () => `hello ${name}`);
});
```

[Start the TypeScript quickstart →](tutorial-typescript.md)

</Tab>

<Tab value="Python">

```python
import fusee

@fusee.workflow("greet")
async def greet(ctx: fusee.Ctx, name: str) -> str:
    return await ctx.step("compose", lambda: f"hello {name}")
```

[Start the Python quickstart →](tutorial-python.md)

</Tab>

<Tab value="Rust">

```rust
use fusee::{Ctx, Error, WorkflowRef};

const GREET: WorkflowRef<String, String> = WorkflowRef::new("greet");

async fn greet(ctx: Ctx, name: String) -> fusee::Result<String> {
    ctx.step("compose", || async { Ok::<_, Error>(format!("hello {name}")) }).await
}
```
