# SDK reference

Use the reference for your SDK to look up types, methods, arguments, and return values. To see how the same call is written in all five languages, use the [cross-language API table](../api.md).

| Language | Reference |
| --- | --- |
| Rust | [Rust API](/api/rust/fusee/index.html) · [Core](/api/rust/fusee_core/index.html) · [Server](/api/rust/fusee_server/index.html) |
| TypeScript | [TypeScript API](/api/typescript/index.html) · [SDK guide](../../bindings/node/README.md) |
| Python | [Python API](/api/python/fusee.html) · [SDK guide](../../bindings/python/README.md) |
| Go | [Go SDK guide](../../bindings/go/README.md). Run `go doc -all` from `bindings/go` for package documentation. |
| Java | [Java SDK guide](../../bindings/java/README.md). Run `mvn javadoc:javadoc` from `bindings/java` to build the Javadoc. |

See [error codes](../errors.md) for failure types and retry behavior.
